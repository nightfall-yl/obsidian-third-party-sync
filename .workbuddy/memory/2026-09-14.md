## 赞赏码宽度最终修正（桌面过大）
- 用户反馈：桌面端赞赏码显得巨大。核查：赞赏码仍为 `width="100%"`，是此前「移动端铺满」需求改的，与表格修复无关（表格改完未动它）。
- 根因：GitHub 剥 `<style>`/媒体查询，无法用 CSS 做响应式；纯 HTML 属性只有固定 `width` 能同时适配两端。`width="30%"` 桌面好看但移动端仅 ~117px 扫不出；`width="100%"` 移动端铺满但桌面满宽（~900px）过大且 Obsidian 移动端不约束原生 `<img>` 宽。
- 处理：`width="100%"` → `width="300"`（README.md / README_zh-CN.md 同步）。桌面 ~300px 不大、移动端 ~300px 清晰可扫且不溢出。源图 docs/reward.jpg 720×720、55KB 不变。
- 结论：赞赏码尺寸 saga 彻底闭环——移动端铺满与桌面不过大两者兼得，靠固定像素而非百分比。
