# Obsidian Third-party Sync

Плагин синхронизации Obsidian, форкнутый из [Remotely Save](https://github.com/remotely-save/remotely-save) с **улучшениями, сфокусированными на безопасности**. Перестроен слой шифрования (AES-256-GCM) и упрощена кодовая база. **НЕ обратно совместим с Remotely Save** — пожалуйста, сделайте резервную копию своего vault перед переключением.

## Отказ от ответственности

- **Это НЕ [официальная служба синхронизации](https://obsidian.md/sync), предоставляемая Obsidian.**
- **⚠️ ВСЕГДА делайте резервную копию vault перед использованием этого плагина.**

## Почему форкнули от Remotely Save?

### Улучшения безопасности (основные доработки)

- **Алгоритм шифрования**
  - Remotely Save: AES-CBC или AES-CTR (RClone)
  - Этот плагин: **AES-256-GCM**
- **Проверка целостности**
  - Remotely Save: Нет (режим CBC уязвим к атакам padding oracle)
  - Этот плагин: **Встроенная проверка AuthTag GCM**
- **Вектор инициализации (IV)**
  - Remotely Save: Производный от пароля (один и тот же IV для всех файлов под одним паролем)
  - Этот плагин: **Случайно генерируется для каждого файла**
- **Длина соли (salt)**
  - Remotely Save: 8 байт (2^64 возможностей)
  - Этот плагин: **16 байт** (2^128 возможностей)
- **Зависимости шифрования**
  - Remotely Save: `crypto-browserify` + `@fyears/rclone-crypt` + Web Worker
  - Этот плагин: **Чистый нативный API браузера `window.crypto.subtle`**

### Упрощение архитектуры

По сравнению с оригиналом этот форк вносит следующие упрощения:

- **Сервисы хранения**: Сокращено с 13 до 3 основных сервисов (S3 / WebDAV / OneDrive). Удалены Dropbox, Google Drive, Box, Azure Blob, pCloud, Yandex Disk, Koofr, Webdis и др.
- **Схемы шифрования**: Объединены с 2 (OpenSSL + RClone) до 1 (**AES-256-GCM**).

## Возможности

- **Поддерживаемые сервисы**: Amazon S3 (и совместимые: Tencent COS, Alibaba OSS, Backblaze B2, MinIO и др.), WebDAV (Jianguoyun/Nutstore, Nextcloud, OwnCloud, Seafile, rclone и др.), OneDrive персональный. См. [документацию по совместимости сервисов](./docs/services_connectable_or_not.md).
- **Сквозное шифрование** ([подробности](./docs/encryption.md)): файлы шифруются локально перед загрузкой с помощью **AES-256-GCM через нативный Web Crypto API браузера**, формат вывода совместим с кодировкой имен файлов base64url от RClone Crypt.
- **Автосинхронизация**: по расписанию, при запуске, при сохранении и при обнаружении изменений на удаленном сервере.
- **Направление синхронизации**: двусторонняя / инкрементальная отправка (режим резервной копии) / инкрементальное получение / варианты с удалением.
- **Защита по коэффициенту изменений**: прерывает синхронизацию, если коэффициент измененных/удаленных файлов превышает порог — предотвращает случайную потерю данных.
- **Обработка конфликтов**: настраиваемо сохранять более новую или более большую версию при конфликтах.
- **Пропуск больших файлов**: пропускает файлы, превышающие настраиваемый порог размера.
- **Синхронизация закладок и каталога настроек** (опционально).
- **Строка состояния**: показывает прогресс синхронизации и время последней синхронизации.
- **Мобильная поддержка**: полная функциональность на Obsidian mobile (Android / iOS), включая сквозное шифрование.
- **Импорт/экспорт URI** для настроек (кроме информации OAuth OneDrive).
- **Очистка пустых каталогов**: автоматически удаляет синхронизированные каталоги, которые стали пустыми.
- **[Минимально инвазивный дизайн](./docs/minimal_intrusive_design.md)**.
- **Полностью open source** ([Apache-2.0](./LICENSE)).
- **[Алгоритм синхронизации](./docs/sync_algorithm.md)**.
- **🌐 Мультиязычность** — UI автоматически следует языку отображения Obsidian (14 языков: English、简体中文、繁體中文、日本語、한국어、Deutsch、Français、Español、Italiano、Nederlands、Dansk、Svenska、Norsk、Русский). Ручная настройка не требуется; при отсутствии перевода переключается на английский.

## Ограничения & примечания

- **Нет синхронизации метаданных — обнаружение удаления зависит от сравнения временных меток.** Рекомендуется использовать с режимами инкрементальной отправки/получения.
- **Простое разрешение конфликтов**: файлы сравниваются по времени изменения; побеждает более новая версия.
- **Облачные сервисы стоят денег.** Все операции (загрузка, скачивание, список файлов, вызовы API) могут облагаться платой.
- **Некоторые ограничения обусловлены средой браузера**, см. [техническую документацию](./docs/browser_env.md).
- **Защищайте свой файл `data.json`** — он содержит чувствительную информацию (ключи S3, пароли WebDAV и др.). Не делитесь с другими; рекомендуется добавить в `.gitignore`.

## Установка

**Вариант 1**: Найдите `Obsidian Third-party Sync` в маркетплейсе сообщественных плагинов Obsidian.

**Вариант 2**: Используйте [Obsidian42 - BRAT](https://github.com/TfTHacker/obsidian42-brat), добавьте репозиторий `nightfall-yl/obsidian-third-party-sync`.

**Вариант 3**: Вручную скачайте `main.js`, `manifest.json`, `styles.css` из последнего релиза и поместите их в каталог `.obsidian/plugins/third-party-sync/` вашего vault.

## Использование

### S3

- Подготовьте данные S3: Endpoint, Region, Access Key ID, Secret Access Key, имя Bucket.
- Заполните настройки и задайте пароль шифрования (если нужно).
- Нажмите значок на боковой панели для ручной синхронизации или включите автосинхронизацию в настройках.

### WebDAV

- Работает с Jianguoyun/Nutstore, Nextcloud, OwnCloud, Seafile, rclone и др.
- Некоторые сервисы требуют плагинов вроде `WebAppPassword`. См. [документацию по настройке WebDAV](./docs/apache_cors_configure.md).

### OneDrive (Персональный)

- Только персональные учетные записи — OneDrive for Business не поддерживается.
- Плагин читает/пишет в `/Apps/third-party-sync/` после авторизации.
- Поддерживается сквозное шифрование (имя vault само по себе не шифруется).

### Автосинхронизация

- Ошибки тихо проваливаются в режиме автосинхронизации.
- Не может работать, пока Obsidian закрыт (техническое ограничение браузерных плагинов).

### Скрытые файлы

- Файлы/каталоги, начинающиеся с `.` или `_`, по умолчанию исключены из синхронизации.
- В настройках можно включить синхронизацию для каталогов `_` и каталога настроек `.obsidian`.
